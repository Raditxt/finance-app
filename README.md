# Finance App

Personal finance tracker, terinspirasi dari buku "The Psychology of Money" (Morgan Housel).

## Stack
- Backend: Bun + Hono + bun:sqlite
- Frontend: Svelte 5 + Vite + TypeScript

## Cara jalanin

### Backend
cd backend
bun install
bun run index.ts
# Server jalan di http://localhost:3000

### Frontend
cd frontend
bun install
bun run dev
# App jalan di http://localhost:5173
